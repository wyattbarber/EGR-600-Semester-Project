EGR 600 Semester Project
========================

This project aims to design an image processing pipeline that can generate graph-like 
representations of trees from RGB images. Such a tool has applications in robotic orchard 
management, particularly in the labor-intensive task of pruning. 

The term paper for this project can be downloaded from [here](https://github.com/wyattbarber/EGR-600-Semester-Project/blob/bf5e3072375044a3fdb201337e6eb74a702b4be8/Report/EGR%20600%20Semester%20Project.pdf).
